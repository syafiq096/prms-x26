# Frontend Design

Use a responsive mission-control layout with clear hierarchy, accessible contrast, keyboard navigation, and explicit loading, empty, success, and error states. MUI theme tokens are the single source of visual truth.

The approved visual direction is a dark operational console: deep navy canvas and sidebar, graphite content surfaces, cyan primary actions, green healthy/available states, amber warnings, and restrained red errors. Avoid a bright white application canvas or decorative science-fiction chrome. Use compact operational density, not a marketing-style hero.

Desktop navigation is a persistent sidebar; mobile navigation is a drawer. Each page begins with a concise contextual header, then presents metrics, filters, and workflow data in reusable surfaces. Maintain sufficient contrast and semantic text labels alongside icons.
